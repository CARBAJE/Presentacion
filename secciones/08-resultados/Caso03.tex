\subsection{Caso 03: Kepler pateado}
\begin{frame}{Resultados — Caso 03: Kepler pateado}
    \textbf{Descripción:} sistema Kepleriano (Sol-Tierra) perturbado con impulsos periódicos de velocidad para inducir caos controlado.\\
    \vspace{0.2cm}
    {\small
    \textbf{Configuración del experimento:}
    \begin{itemize}
        \item Horizonte de simulación: $t_{short}=0.5$ años, $t_{long}=4.0$ años.
        \item Integrador: \texttt{IAS15} con paso $\Delta t=2\times10^{-4}$ años.
        \item Masas originales: $(1.0,\ 3\times10^{-6})$ M$_\odot$.
        \item Impulsos: periodo $0.25$ años, $\Delta v=0.05$ UA/año.
        \item Optimización: población 160, 45 épocas, $\omega_{periodicidad}=0.25$.
        \item \textbf{Resultado:} Masas optimizadas $(1.045,\ 2.8\times10^{-6})$ M$_\odot$.
        \item Reducción de caos: $\lambda_{inicial}=5.62 \rightarrow \lambda_{opt}=-2.57$.
    \end{itemize}
    }
\end{frame}

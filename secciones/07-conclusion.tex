\section[Conclusiones]{Conclusiones y Líneas Futuras}
\begin{frame}{Conclusiones}
    \textbf{Principales logros alcanzados}
    \begin{itemize}
        \item Pipeline completo: simulación (REBOUND), análisis de estabilidad (Lyapunov) y optimización evolutiva (GA).
        \item Mejora significativa en estabilidad: reducción de $\lambda$ en 3/4 casos; captura estable del intruso en Caso 04.
        \item Sistema reproducible y parametrizable con visualización 2D/3D.
        \item Instrumentación de rendimiento para identificar y optimizar cuellos de botella.
        \item Validado para 2–3 cuerpos con integradores \texttt{IAS15}/\texttt{WHFAST}.
    \end{itemize}
\end{frame}

\begin{frame}{Líneas futuras}
    \begin{itemize}
        \item Extender a sistemas de $n>3$ cuerpos con paralelización (GPU/HPC).
        \item Incorporar física avanzada: masas variables, fuerzas no gravitacionales, colisiones.
        \item Optimización multiobjetivo: balancear $\lambda$, periodicidad y distancias mínimas.
        \item Calibración con datos reales (efemérides) y análisis de sensibilidad Monte Carlo.
        \item Empaquetado como librería Python.
    \end{itemize}
\end{frame}
